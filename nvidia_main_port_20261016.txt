実装
  * Cluster/Band のホスト格納 MAGMA、協調 GEMM、Band の k 点別 GPU グループ。
  * HIP の行列構築・加算・転置・スケーリング・Hermitian 化・spinor 構築を協調処理へ接続。
  * scf.eigen.lib=gpusolver3、scf.mgpu.enable、GPU 可視範囲と個数上限。
  * Cluster の容量不足時の MAGMA -> ELPA/COSMA -> CPU 経路とホストメモリー見積り。
  * 密度行列、Hamiltonian、軌道・XC グリッド、重なりグリッド、projector/radial、
    力、全エネルギー、mixing の範囲分割と local GPU / remote MPI / CPU 回復。
  * GPU UUID によるプロセス間排他、準備・実行・結果取得・解放の分離、
    HIP と OpenMP のデバイス割当復元、通信パケットと CPU 作業領域の上限制御。
  * hipMAGMA 2.10.0 の論理デバイス写像を versioned patch で追加。
    既存 Ozaki-II patch を保持し、単一 GPU/MGPU アダプターの mutex を共有。

AMD 固有の統合
  * CUDA/cuBLAS/OpenACC を HIP/hipBLAS/OpenMP target に置換。
  * NVIDIA openmx_cusolver_compat.c の hook は AMD magma_openmx.cu の既存入口へ接続。
  * NVIDIA orbs_grid_gpu.h / set_hamiltonian_gpu.cu の容量回復は AMD の
    Set_Orbitals_Grid.c / Set_Hamiltonian.c と既存 HIP カーネルへ統合。
  * MI300A の native FP64、workspace 再利用、APU の force/projector 既定値を保持。
    Radeon の GEMMul8、refinement、Force4B の streaming/rank turns も保持。
  * 性能目的の分割は OPENMX_MGPU_SOLVER=auto/magma、OPENMX_MGPU_GEMM=auto/1、
    OPENMX_GPU_WORKERS=1 で選択。通常は owner の既存経路を優先する。
    Instinct の判定と XGMI トポロジー判定を AMD 用に実装。
  * DC/DC-LNO/Krylov の既存投影固有値ソルバーを保ち、共通処理の回復を適用。
