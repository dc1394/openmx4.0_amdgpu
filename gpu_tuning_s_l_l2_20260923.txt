Changes
  Collinear multi-k GPU solves retain transformed S(k) within a geometry
  and compact eigenvectors between the occupation and density-matrix
  passes within an SCF iteration. Caps: overlap 512 MiB/rank, eigenvectors
  1024 MiB/rank; each also limited to 1/64 of available node RAM / local
  ranks. Cache misses retain the original recomputation path.
  The collinear band crossover changes from 800 to 400 basis functions.
  Matrices n <= 512 use eight concurrent GPU turns; larger matrices keep
  two. Existing environment overrides remain available.
  Before a memory-based collinear band fallback, reclaim reproducible
  device scratch and retry the ORIGINAL admission budget. Explicit
  OPENMX_BAND_GPU_DIAG=0 skips this eviction. Geometry boundaries reset
  the construction and overlap caches.
  Noncollinear multi-k GPU solves borrow the current SCF packed H/S and
  imaginary nonlocal matrices, avoiding repeated gathers in both passes.
  All ranks agree before skipping collectives. No extra matrix copies;
  OPENMX_BAND_NONCOL_PACKED_CACHE=0 restores the legacy gathering path.
  Serial collinear cluster spin roots retain a host copy of transformed
  overlap while releasing dense device matrices between spins. Cap:
  2048 MiB/root, further limited to 1/32 of available node RAM/root.
  Small density tables persist on device: owner cap 64 MiB, local cap
  32 MiB/rank, additionally limited by shared free VRAM. Static joins are
  validated once per geometry. Failed allocations/copies clean up.
  In GPU BAND mode only, release density and shared orbital tables after
  Force3, their last force-stage consumer, to admit the VNA GPU batches.
  Other solvers preserve their original force admission behavior.
  CPU numerical paths, numerical kernels, precision and compiler flags
  are unchanged. README.md documents the cache caps and opt-out settings.
  Test tools now select S/L/L2/L3, isolate original inputs, and retain
  suite metadata. L3 remains the default; comparisons reject mixed suites.

Accuracy criteria
  Absolute energy error <= 1e-7 Ha; maximum absolute Cartesian force
  component error <= 1e-7 Ha/bohr; complete finite outputs and matching
  atom identities/integration grids. Reference coordinates may differ by
  one printed unit (1e-5); baseline/candidate coordinates must match exactly.
  The built-in signed force sum alone is not the acceptance criterion.
  Numerical PASS requires completed status, return code zero and the strict
  comparison. Interrupted, timed-out or memory-guarded runs are not passes.
