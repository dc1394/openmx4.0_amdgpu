Implementation
  - Per-worker overlap/kinetic Bessel caches; atomic per-atom timing.
  - Received nonlocal products and CPU cluster density-matrix assembly
    parallelized over independent atoms; no MPI calls in the new workers.
  - Dynamic-team scratch sizing in energy/stress, XC stress loop-counter fix.
  - Radial spline endpoint and out-of-support handling, contracted halo indices.
  - Final density reuses normal SCF resident orbital/CSR tables; overflow-safe
    density memory estimates. Existing AMD GPU density-matrix assembly remains.
  - scf.fp32.enable (default on) controls arithmetic independently of GEMMul8.
    Off overrides FP32 refinement and DF orbital/grid requests and promotes
    projector contractions to FP64; existing float storage is unchanged.
  - Additional review fixes: nested radial loop's grid index is local to its
    worker; collinear band refinement config/cycle reset precedes admission.
  - Optional host profiling, hybrid --threads/--mpirun suite-runner options.
  AMD HIP/MAGMA and MI300A policies retained. CUDA kernel-stack scanning and
  NVHPC build settings are backend-specific and were not transplanted.
